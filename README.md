# Student Management System using SQL

## Project Overview
This project is a beginner-level SQL project developed using Microsoft SQL Server Management Studio (SSMS).

The main goal of this project is to understand how databases work and how SQL queries are used to store, manage, update, and retrieve student information.

This project simulates a real-time Student Management System where student records are maintained inside a database table.

---

## Technologies Used
- SQL
- Microsoft SQL Server (SSMS)

---

## Concepts Covered
This project covers important SQL concepts such as:

- CREATE DATABASE

---

## Table Information

### Table Name:
students

### Columns Used:
| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| id | INT | Student ID |
| name | VARCHAR(50) | Student Name |
| branch | VARCHAR(20) | Department |
| gender | VARCHAR(10) | Gender |
| age | INT | Student Age |
| marks | INT | Student Marks |

---

## Operations Performed

### 1. Insert Student Records
Inserted multiple student records into the database table.

### 2. Retrieve Data
Used SELECT queries to display student details.

### 3. Filter Data
Used WHERE clause to filter records based on conditions.

### 4. Sorting
Used ORDER BY to sort students based on marks.

### 5. Grouping
Used GROUP BY to group students department-wise.

### 6. Aggregate Functions
Used AVG(), COUNT(), MAX(), and MIN() functions.

### 7. HAVING Clause
Used HAVING clause to filter grouped data.

### 8. Update Records
Updated student marks using UPDATE query.

### 9. Delete Records
Deleted unwanted records using DELETE query.
